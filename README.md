# 먼작귀 방치 토벌대 🐹🐱🐰

치이카와 · 하치와레 · 우사기와 함께하는 비영리 팬메이드 방치형 RPG.
원작 「먼가 작고 귀여운 녀석」(나가노)의 세계관 — 노동 게시판의 풀뽑기, 보수, 키메라 토벌, 토벌 자격 — 을 참고했어요.

## 실행
설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 플레이
- **전투**: 동료들이 자동으로 키메라를 공격해요. 화면을 톡톡 누르면 같이 공격! 10마리를 잡으면 다음 스테이지, 10스테이지마다 30초 제한 보스전.
- **🐹 동료**: 보수로 하치와레·우사기를 합류시키고 레벨업. Lv.10마다 공격력 ×2, Lv.10에 스킬 해금.
  - 치이카와 「울먹 각성!」 치명타 확률 +50%
  - 하치와레 「어떻게든 될 거야!」 공격 속도 2배
  - 우사기 「우라!! 야하!!」 DPS×30 일격
- **🌿 노동**: 풀뽑기, 포장마차, 기타 버스킹, 라멘 가게 알바… 꺼둔 동안에도 보수가 쌓여요 (최대 12시간).
- **🍜 먹거리**: 라멘(공격력×2), 푸딩(보수×2), 고로케(속도×1.5) 버프.
- **📜 자격 시험**: 스테이지 40 이상에서 도전. 처음부터 다시 시작하는 대신 자격 포인트(공격력·보수 +10%/pt)를 영구히 얻고 등급이 올라가요. 토벌 3급부터 스킬 자동 사용.

진행 상황은 브라우저 localStorage에 자동 저장돼요.
