# 먼작귀 RPG ~토벌 자격 시험 대작전~ 🐹🐱🐰

치이카와 · 하치와레 · 우사기와 함께하는 비영리 팬메이드 턴제 RPG.
원작 「먼가 작고 귀여운 녀석」(나가노)의 세계관 — 노동 게시판, 풀뽑기, 보수, 키메라 토벌, 토벌 자격 시험 — 을 참고했어요.

## 실행
설치 없이 `index.html`을 브라우저로 열면 바로 플레이할 수 있어요.

## 조작
- 이동: 방향키 / WASD (모바일은 화면 왼쪽 아래 버튼)
- 조사 · 대화 · 다음: Space / Enter (모바일은 「조사」 버튼)
- 메뉴: Esc

## 이야기
1. 노동 게시판의 갑옷씨에게 **풀뽑기** 의뢰 받기 → 풀숲에서 풀 5개 뽑기
2. **풀숲의 키메라 토벌** — 풀숲에서 우사기를 만나 동료로!
3. 깊은 숲의 **「숲의 주인」** 토벌
4. **토벌 자격 시험**: 동굴 깊은 곳의 「크고 강한 녀석」 토벌
5. 특별 의뢰: 마을 남쪽 **바닷가**의 「세이렌」 토벌 → 토벌 4급
6. 특별 의뢰: 바닷가 너머 **수수께끼의 유적**의 「스핑크스」 토벌 → 토벌 3급
7. 그 뒤에는 반복 토벌 의뢰로 자유롭게 성장

## 동료 (최대 4명 함께 출전, 쉬는 동료도 경험치 절반)
| 동료 | 만나는 곳 | 특기 |
|---|---|---|
| 치이카와 · 하치와레 | 처음부터 | 공격 · 회복/응원 |
| 우사기 | 풀숲 (풀숲 토벌 의뢰 중) | 전체 공격 |
| 모몽가 | 마을 연못가 (풀숲 토벌 의뢰 이후) | 적 공격력 다운 |
| 시사 | 라멘 가게 앞 (숲의 주인 토벌 이후) | 한 명 회복 · 피해 감소 |
| 쿠리만쥬 | 라멘 가게 앞 (자격 시험 중) | 튼튼함 · 자가 회복 |
| 랏코 | 마을 (토벌 5급 합격 후 대련에서 승리) | 최강 공격 |

## 시스템
- 키 큰 풀숲·동굴을 걸으면 적과 마주치는 턴제 전투 (공격 / 스킬 / 아이템 / 방어 / 도망)
- 레벨업으로 스킬 습득: 치이카와 「힘껏 찌르기」「울먹 각성」, 하치와레 「어떻게든 될 거야!」「기타 응원송」, 우사기 「우라!」「야하!!」 …
- 도구점(약초·보리차·주먹밥, 무기·부적 강화), 라멘 가게(전원 회복), 치이카와네 집(휴식·저장)
- 진행 상황은 브라우저 localStorage에 자동 저장

## 그림 출처 (`img/`)
- `chiikawa/hachiware/usagi.png`: 직접 제공해 주신 이미지에서 배경을 지운 것 (대화창·전투)
- `spr_*`, `npc_*`: Chiikawa Fandom 위키의 공식 캐릭터 이미지 (맵 캐릭터, 갑옷씨·쿠리만쥬·랏코·시사·모몽가)
- `mon_*`: Chiikawa Fandom 위키(영어·중국어판)의 애니메이션·만화 이미지에서 배경을 지워 잘라 낸 것
- 맵 타일·건물은 코드로 직접 그린 그림
